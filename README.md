# Teaboom.ru

Карточка товара интернет-магазина Teaboom.ru: карточка товара «Ананасовый улун», выбор веса, счётчик корзины и адаптивное меню категорий.

## Демо

https://daragondd.github.io/teaboom/

## Запуск локально

Просто откройте `index.html` в браузере — сборка не требуется.

Либо поднимите локальный сервер (чтобы корректно работали относительные пути)
